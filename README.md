# ניתוח נתוני כדורגל
hiiiiiiiii
סקריפט Python לניתוח בסיסי של נתוני כדורגל באמצעות pandas.

## תיאור

הקובץ `friday.py` מכיל את הפונקציה `analyze_football_data`, שמקבלת DataFrame ומדפיסה סיכום סטטיסטי:

- מספר קבוצות ורשימת שמות
- ממוצע שערים וקבוצה עם הכי הרבה שערים
- ממוצע בעיטות
- יחס ניצחונות/הפסדים וקבוצה עם היחס הגבוה ביותר

## דרישות

- Python 3.7+
- [pandas](https://pandas.pydata.org/)

```bash
pip install pandas
```

## שימוש

### הרצה עם נתוני הדמו המובנים

```bash
python friday.py
```

### שימוש בפונקציה עם נתונים משלך

```python
import pandas as pd
from friday import analyze_football_data

data = {
    'קבוצה': ['מכבי תל אביב', 'הפועל תל אביב', 'בית"ר ירושלים'],
    'שערים': [45, 32, 28],
    'בעיטות': [120, 110, 98],
    'ניצחונות': [18, 11, 8],
    'הפסדים': [3, 9, 11]
}

df = pd.DataFrame(data)
analyze_football_data(df)
```

## מבנה הנתונים

| עמודה     | תיאור              | חובה |
|-----------|--------------------|------|
| `קבוצה`   | שם הקבוצה          | לא   |
| `שערים`   | מספר שערים         | לא   |
| `בעיטות`  | מספר בעיטות        | לא   |
| `ניצחונות`| מספר ניצחונות      | לא*  |
| `הפסדים`  | מספר הפסדים        | לא*  |

\* חישוב יחס ניצחון/הפסד דורש את שתי העמודות `ניצחונות` ו-`הפסדים`.

הפונקציה בודקת אילו עמודות קיימות ומדפיסה רק את הניתוחים הרלוונטיים.

## הערות

- חלוקה ב-0 בהפסדים מטופלת על ידי החלפה ב-1 כדי למנוע שגיאות.
- העמודה `יחס ניצחון/הפסד` נוספת ל-DataFrame במהלך הניתוח.
